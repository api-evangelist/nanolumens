# NanoLumens

> NanoLumens is an American designer and manufacturer of direct-view LED (dvLED) displays
> and video walls, headquartered in Atlanta, Georgia and founded in 2006 by Rick Cope. Its
> AWARE platform and NanoSuite display-management software market a JSON REST API and
> webhook-based alerting for remote display diagnostics and fleet monitoring, but that API
> is delivered only to authenticated NanoSuite tenants — as of 2026-08-04 NanoLumens
> publishes no public developer portal, no API reference, and no machine-readable
> specification (OpenAPI, AsyncAPI, GraphQL SDL or Postman collection).

## APIs

No publicly documented API. The NanoSuite product page states the platform offers a
"JSON REST API" and "email, text, or webhook based alerts", and the AWARE production
gateway resolves at `api.nanolumens.com` (a WSO2 API gateway), but neither the gateway
nor any reference for it is reachable without a customer tenant.

- [NanoSuite — display management and monitoring](https://www.nanolumens.com/nanosuite/): product page describing the JSON REST API and webhook alerting
- [AWARE platform](https://aware.nanolumens.com/): the cloud platform the API belongs to
- [ISAAC ecosystem — NanoLumens](https://www.isaacplatform.com/ecosystem/nanolumens): the partner platform NanoSuite is built on
